3. How each signal is queried (PromQL in serve_app.py / online.py):
- cpu: 'sum(rate(container_cpu_usage_seconds_total{deployment="{dep}",container!=""}[2m]))'
- rps: 'sum(rate(http_requests_total{deployment="{dep}"}[1m]))'
- mem: 'sum(container_memory_working_set_bytes{deployment="{dep}",container!=""})'
- pod_count: 'count(kube_pod_info{deployment="{dep}"})'
- ready_pods: 'sum(kube_pod_status_ready{deployment="{dep}",condition="true"})'
Queried via VictoriaMetrics /api/v1/query_range with step="60s" over a 60-minute lookback window.

  - reason: str

8. How Replica Count is Produced:
- Formula: desired = max(min_replicas, math.ceil(p90_abs / (cpu_request * target_util)))
- Scale-down is never recommended: if desired > current_replicas, action="scale_up"; else action="hold".
